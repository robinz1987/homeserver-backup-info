HomeServer Backup

A private utility for securely backing up personal home server data to Google Drive.

Purpose

This application uses rclone to automate encrypted backups of personal, self-hosted services.

Google Drive Access

Google Drive access is authorized by the account owner using OAuth 2.0 and is used for managing backup files.

Security

Backup files are encrypted locally before being uploaded to Google Drive. The application is intended for personal use only and is not offered as a public service.

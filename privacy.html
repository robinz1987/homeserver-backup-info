Privacy Policy

HomeServer Backup

Last updated: November 13, 2026

1. About this application

HomeServer Backup is a privately operated, non-commercial utility for creating encrypted backups of personal home server data. It uses rclone and Google Drive. It is not offered as a public service.

2. Google Drive permissions

The application uses Google OAuth 2.0 to access Google Drive with authorization from the account owner. Depending on the permissions granted, this access may include reading, creating, modifying and deleting Google Drive files.

These permissions are used exclusively for managing the owner's backup files, including uploading, verifying and removing backups according to the configured retention rules.

3. Data processed

The application processes backup archives, associated file metadata and the OAuth credentials required for Google Drive access. Backup archives may contain personal data from the owner's self-hosted services.

4. Encryption and storage

Backup archives are encrypted locally using rclone crypt before transfer to Google Drive. Google Drive stores the encrypted files and associated storage metadata.

OAuth credentials and encryption configuration are stored locally on the owner's home server. They are not published on this website.

5. Use and disclosure

Google Drive data is accessed only for the backup purposes described above. The application does not use Google user data for advertising, profiling or sale.

Encrypted backup files are transferred to Google Drive as the selected storage provider. The application does not intentionally share backup contents with other users.

6. Retention and deletion

Backups are retained according to locally configured backup and retention schedules. The account owner can remove backup files from Google Drive and revoke application access through Google Account settings.
